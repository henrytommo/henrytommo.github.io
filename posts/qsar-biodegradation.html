QSAR Biodegradation Prediction

September 2026

A little while ago, I followed a great tutorial on writing up a simple graph neural network from scratch. I was keen to put these learnings about GNNs into chemical context, and at the time was reading some cool stuff about predicting the biodegradability about certain compounds using ML. A quick Google search found the QSAR dataset, and I jumped right in to try out my new GNN skills. However, my choice of dataset was probably more suited to a different type of model (also tried that out); the great thing about GNNs for molecular prediction is the properties they "infer" within their hidden layers. This dataset already had those properties as part of the tabular dataset, and those properties calculated by "real" chemistry will probably outperform whatever relationships are found in my simple model. Regardless, it was a great learning experience.

Data prep

  • ~1,055 molecules, binary target (RB / NRB), Mansouri 2013 dataset; class-imbalanced (~34% RB).
  • 41 precomputed QSAR descriptors as base features.
  • Stratified k-fold; scaling fit inside each fold (no leakage).
  • Dataset was fairly clean, drop rows with failed features (1,055 down to 1,050).
  • Added SMILES - molecular graphs for the GCN (structure + QSAR globals).

Feature engineering

  • +3 RDKit 2D descriptors: MolLogP, MolWt, TPSA (checked overlap first — none direct).
  • +6 xTB electronic descriptors via dxtb (GFN1-xTB, RDKit ETKDGv3+MMFF 3D): HOMO-LUMO gap, IP, EA, electrophilicity, Fukui±, WBO (total/max), dispersion -> 53 features total. Cached (xtb_features.csv) as they're slow to compute.
  • Leak-free per-fold feature ranking searched jointly with hyperparams; final cap at 20 features (GCN ranks via XGBoost importances — cheaper than GNNExplainer over folds).

Models & reasoning

  • XGBoost — strong tabular baseline, handles collinearity/nonlinearity, gives feature importances.
  • Logistic regression — interpretable linear baseline, L1/elastic-net for sparsity, class-balanced.
  • GCN — tests whether raw structure beats hand-made descriptors.

Mistakes / dead ends

  • Stereoisomer flags + GINEConv - thought this may give some insights as whatever enzymes are being used to break down these chemicals will likely be stereospecific. However, only about 1% were chiral, and the GINEConv gave worse results so that was scrapped.
  • GCN tuning "mirage": a config tuned to test F1 0.816 but delivered 0.783 across seeds → fixed by 3× repeated 5-fold CV.
  • 4 molecules with unphysical ΔSCF (IP up to ~1785 eV), so added physical-bounds guard, and dropped them.
  • Code stuff: xgboost must load before torch/dxtb (OpenMP clash) + OMP_NUM_THREADS=1.

Packages tried

  • dxtb (kept), RDKit, torch-geometric, xgboost, sklearn.

Key results / findings

  • All three models get about the same metrics, around F1 ≈ 0.78–0.79, ROC-AUC ≈ 0.92 — task is saturated / data-limited, not feature-limited (extra descriptors rank well but don't improve much).
  • Capping 53 → 20 (or 15) features costs nothing and makes everything simpler.
  • Errors only partly shared — 34% of misses are single-model; there were 97 molecules (9.2%) wrong for all three, both classes.
  • Ensemble (xgb+logreg soft-vote) beats every single model internally; GCN internally droppable.
  • External validation (670 held-out): both generalise, no overfitting; GCN slighlty better than the ensemble out-of-sample (learns something from 3D structure).
